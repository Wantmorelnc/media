# WYVMPF Media

Public image host for Wyoming Veterans Memorial Park Foundation social posts (Buffer needs a public URL per image).

- Only photos approved for posting go here. No photos with identifiable minors.
- Folders by posting month: `YYYY-MM/`.
- Direct link format: `https://raw.githubusercontent.com/wantmorelnc/media/main/YYYY-MM/<file>.jpg`
- Never delete or rename a file once it has been used in a post (the link would break).
